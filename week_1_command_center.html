GATE ECE 2027 — WEEK 1 COMMAND CENTER PAGE 3 OF 4 (SOP CHEAT SHEET)

📋 Standard Operating Procedures (SOP) Quick Reference Card

🟢 SOP 0: Energy-State Awareness Check
Green (Alert) = Execute full plan. | Yellow (Tired) = Switch block to PYQ problem solving (active focus).
Red (Exhausted) = Execute Emergency Day Protocol (1 hr PYQs + 30 min Error Log + 15 min Short Notes).
🛠️ SOP 1: Deep-Work Environment Control
Phone in another room / airplane mode. Single window open. Physical timer on desk. Write random thoughts on Distraction Card → address ONLY during 10-min break. Break rule: Walk, water, stretch. No social media.
📖 SOP 2: 3-Step Theory Acquisition (Morning)
Min 0–20 (Concept Scan): Watch lecture at 1.5x or read textbook. NO note-taking! Focus on WHY.
Min 20–40 (Example Attack): Cover solution, try solo. If stuck >2 min, reveal line 1.
Min 40–50 (Raw Scratch): Write formulas/conditions on rough pad. Say "Can I teach it?" out loud.
🎯 SOP 3: 3-Pass PYQ Solving Rule (4-Minute Algorithm)
Pass 1 (3 min Solo): Attempt from memory. Solved? → Mark Green.
Pass 2 (+1 min Formula Check): Open SHORT NOTES ONLY (not solution!). Solved? → Mark Yellow.
Pass 3 (+2 min Line 1 Hint): Read line 1 of official solution. Close it. Finish solo → Mark 🔴 RED STAR.
🔄 SOP 3.5: Red Star Re-Attempt Protocol
Re-attempt 🔴 questions closed-book **2 days later** (at 7:30 AM warm-up). Solved? → Clear star. Failed? → DOUBLE RED STAR ⭕ (High priority item for Saturday analysis).
📝 SOP 4: 1-Page Short Notes Protocol (6:30 PM Window)
Max **1 side of A4 per sub-topic**. Include: Formulas (blue) + Properties (black) + Special Cases (green) + TRAPS (RED pen) + Connections to future subjects (pencil). NO long proofs or definitions.
🧠 SOP 5: "Blank Sheet" Active Recall & Audit
15-min memory dump on blank A4 → Line-by-line audit against Short Notes → Highlight missing in **YELLOW** (weak recall), circle wrong in **RED** (concept error) → **5-min Re-Encode**: write weak items again from memory.
📓 SOP 6: 3-Line Error Log Protocol (8:30 PM)
For every 🔴 RED STAR question, write 3 lines: 1. The Trap | 2. My Error (brutally honest) | 3. The Rule for future self.
🌙 SOP 7.5: Pre-Sleep Micro-Review (9:10 PM)
5-minute slow read of today's Short Notes page in bed. Exploits sleep-dependent memory consolidation during REM.

🚨 Contingency Protocols (When things break)

• Overslept < 1 hr: Compress breaks to 5 min, skip GA theory (just do GA PYQs).
• Overslept 1–2 hrs: Skip Spaced Revision (4 PM). Shift Active Recall to 5:40 PM.
• Lost 3+ hrs: Execute Minimum Viable Day (Theory Block 1 + Math PYQ Block 1 + Short Notes + Error Log = 3.5 hrs).
• Fell behind 1+ days: Do NOT double up. Shift schedule forward by 1 day. Sat test moves to Sun morning.

🚦 The 5 Non-Negotiable Rules

1. NEVER start a block asking "What do I do now?" (Desk prepped at 9:10 PM night before).
2. NEVER spend >6 minutes on a single PYQ (Enforce 3-Pass Rule SOP 3).
3. NEVER skip the 8:30 PM Error Log (Quality error analysis beats sheer volume).
4. NEVER skip Sunday rest (Offline downtime consolidates long-term memory).
5. NEVER study new theory after 4 PM (Afternoon/Evening is for practice & recall).
